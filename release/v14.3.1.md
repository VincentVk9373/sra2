# Release v14.3.1

## Fix — FR "Orc" metatype renamed to "Ork"

The French metatype compendium entry was named "Orc", while the English pack, the `Ork.webp` image and the NPC generator data all say "Ork". The generator looks up metatypes by name, so for French games it silently fell back to a rebuilt metatype with no description, no reference and no compendium link. The entry is renamed to "Ork" (same id and data), so id-based references keep working and the NPC generator finds it again.

## Fix — Section tabs dead on read-only sheets

On a non-editable feat or vehicle sheet — typically an item opened from a locked compendium — the section tabs no longer responded and the sheet stayed stuck on its first section. Foundry disables every button on a read-only sheet along with the real form fields; the tabs are buttons, but they only switch the visible section and never touch the document. They are now re-enabled after the sheet renders: navigation works again and the sheet stays exactly as read-only as before.

## Fix — Sheets could lose their background without a core theme class

The SRA2 theme variables were only emitted when the body carried a core `theme-light`/`theme-dark` class. With the client's theme setting on Default and no browser colour-scheme preference, Foundry strips both classes, the variables disappear, and sheet backgrounds built on them (gradients) became invalid — leaving sheets with no background at all. The variables are now bound to the SRA2 theme class alone, identical in light and dark, so they survive the no-theme-class case.

Thanks to badaz for the three fixes.
