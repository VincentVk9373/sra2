# Release v14.4.1

## Fix — RR on a specialization you don't have rolled Strength only

An RR given by a feat or a contact on a specialization the character doesn't have (for example a Media contact giving RR to "Spec: Media") showed up under the right skill on the sheet, but its roll ignored that skill: it defaulted to the Strength attribute alone. This happened whenever the RR target had been set by dragging the specialization onto the feat, which stored its name instead of its slug.

- These rolls now use the linked skill and its attribute (e.g. Networking + Charisma), plus the RR.
- Dragging a skill or specialization onto an RR entry now stores its slug. Existing feats and contacts work without any change.

Thanks to RobFerret for the report.

## Fix — Custom weapons rolled Strength when their specialization wasn't owned

A custom weapon (AMP) whose specialization the character doesn't have, and with no linked skill set, rolled the bare Strength attribute. It now falls back to the specialization's linked skill and attribute. Skill and specialization names typed in any language (e.g. "Armes à distance") are also recognised.

Thanks to RobFerret for the report.

## Fix — Checkboxes overlapping their label

With the SRA2 theme, checkboxes outside the system sheets (for example in the module management window) collapsed and their icon overlapped the label next to them. They now keep their normal size.

## Improvement — Feat preselected when creating an item

The "Create Item" dialog now preselects **Feat** instead of Skill.
