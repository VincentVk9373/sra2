# Release v14.4.0

## Feature — Reroll a roll

Roll results in the chat now have a **Reroll** button that replays the exact same roll: same dice pool, same risk dice, same advantage/disadvantage mode, same targets.

- Following the reroll rule, only the **first roll's complication counts**: it carries over to the reroll, and any complication rolled by the reroll's own dice is ignored.
- A roll can only be rerolled **once**. The original result is then marked as superseded: its Reroll and Apply Damage buttons are disabled and a banner points to the new result.
- Its side effects are not applied twice: drain wounds and the GM complication suggestions only come from the original roll.
- Only the author of the roll or a GM can reroll it, and a double click cannot trigger two rerolls.
- Rolls made in NPC mode (no dice rolled) cannot be rerolled.

Thanks to l34ndr3-web.

## Feature — NPC mode (fixed success threshold)

A new 🤖 button in the character sheet header switches an actor to **NPC mode**: its rolls no longer roll dice and use the NPC success threshold instead, `round(dice pool / 3) + RR + 1`.

- Applies to skill, specialization, attribute and weapon rolls, and to defense, counter-attack and matrix defense/counter-attack.
- The threshold is recomputed when the attribute is changed in the roll dialog, weapon RR included.
- The setting is stored on the token: on an unlinked token, toggling it from the token's sheet only affects that token.

Thanks to l34ndr3-web.

## Feature — German localization

The system is now available in **German**: full interface translation and a German item compendium (`Anarchy Items (DE)`), with the same items, ids and slugs as the English and French packs. With Foundry set to German, the German compendium is used automatically.

Thanks to headcrash2k.

## Feature — Matrix damage threshold bonus is applied

Feats with a matrix threshold bonus now actually raise the matrix damage thresholds (light, severe and incapacitating), like the physical and mental bonuses already did. The bonus only applies when the character has a matrix persona (active cyberdeck or emerged).

## Improvement — Character sheet layout cleanup

- The header and footer are now regular parts of the sheet: only the content scrolls, and text no longer slips under the footer.
- Video tokens (`.webm`) are displayed correctly in the sheet header.
- A token without an image shows Foundry's default portrait, which can be clicked to choose one.
- The bio editor scrolls correctly, and the compact mode (sheet window shrunk in height) follows the new layout.
- Connection mode and astral state badges share a consistent set of colors.
- Actor sheets open 50px taller by default.

Thanks to Kyle-B.

## Fix — NPC generator dialog always in French

The NPC generator dialog now shows power levels, archetypes, metatypes and budgets in English when the interface is not in French, and its error message is translated.

Thanks to kenken-trpg.

## Fix — Duplicate "Cybercombat" specialization in the NPC generator data

The Cybercombat specialization was keyed `spec_complex-forms` in the NPC generator data and was silently overwritten by the "Complex Forms" entry. It now uses its real slug, `spec_cybercombat`.

## Development

- `npm run typecheck` passes with 0 errors (88 before).
- The test suite runs completely again: the dice roller tests were silently skipped because Foundry globals were missing at import time. 116 tests now run, against 90 before. Thanks to kenken-trpg.
