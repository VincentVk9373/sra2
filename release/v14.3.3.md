# Release v14.3.3

## Fix — Manifest warning about unknown `download-x.y.z` keys on Foundry V14

Foundry V14 now validates every key of a system manifest and warned on load that `system.json` contained 36 unknown keys (`download-13.0.2` … `download-14.3.2`). Those keys were appended by the release workflow at every tag as a "download history"; nothing reads them, and the GitHub Releases page already keeps that history.

- Removed all `download-<version>` entries from `system.json`. Only the standard `download` key remains.
- The release workflow no longer appends a `download-<version>` entry, so the warning cannot come back on future releases.
